# ENDLESS — MVP план (8 недель)

**Цель MVP:** законченная история на 15–25 минут из 6 этапов петли с финалом, собранная в `.exe`. Плюс портфолио-пакет: видео, скриншоты и разбор дизайна.

**Что уже есть в репозитории (код):**

| Класс | Назначение | Что делает дизайнер |
|---|---|---|
| `ALoopManager` | Этапы петли, переход между ними, повтор замочного этапа, затемнение и пробуждение у кровати | Заполняет список `Stages` (имя, заметка, `bRequiresObjective`), вешает события в Level Blueprint |
| `AAnomaly` | Изменение квартиры на диапазоне этапов `FirstStage..LastStage` | Простое: `ShowWhenActive` / `HideWhenActive`. Эскалация: BP-наследник, `OnStageChanged(Stage, Level)` |
| `ALoopExit` | Триггер сразу за входной дверью: шаг в него = конец круга | Ставит один на уровень |
| `ALoopDoor` | Дверь, открывается на E, в начале круга снова закрыта | Ставит входную (и другие) двери, `OpenAngle` задаёт сторону |
| `AEndlessCharacter` | Игрок: камера, ходьба, фонарик (F), взаимодействие (E) | BP-наследник: тюнинг фонарика, звуки |
| `IInteractable` | Интерфейс для E | Сюжетные предметы: `Interact` → `LoopManager.CompleteObjective()` |

**События LoopManager для Level Blueprint:**
- `OnStageStarted(Stage)` — сменить свет и Post Process, запустить скриптовое событие этапа.
- `OnStageRepeated(Stage, RepeatCount)` — игрок не нашёл деталь, усилить подсказку.
- `OnFinale` — финал (петля больше не телепортирует).

**Для тестов:** `DebugStartStage` запускает игру сразу с нужного этапа, `bDebugShowStage` выводит этап на экран.

## Неделя 0 — Окружение (1–2 дня)

- [x] **Visual Studio 2022** (Community): workload *Game development with C++* + *.NET desktop development*.
- [x] Двойной клик по `Endless.uproject` → «Rebuild now? → Yes».
- [ ] git + GitHub (`.gitignore` уже есть), Git LFS для ассетов.

## Неделя 1 — Greybox и петля ⟶ **M1: «Петля работает»**

- [x] Уровень `L_Apartment`, блокаут квартиры по планировке (~10×12 м): спальня, коридоры, гостиная с закутком, прихожая, кухня, уборная. Все проёмы 100 см.
- [x] `LoopManager` у кровати в спальне (стрелка — куда смотрит проснувшийся игрок). `LoopDoor` во входной двери, `LoopExit` сразу за ней.
- [x] Переход читается: шаг за входную дверь → затемнение → пробуждение в спальне.
- [x] В `Stages` 6 пустых этапов с заметками из GDD.

**Готово, когда:** можно пройти 6 кругов, этап виден в debug, пробуждение не сбивает с толку.

## Неделя 2 — Ритм на плейсхолдерах ⟶ **M2: «Скелет истории»**

- [ ] На каждый этап 2–3 изменения из кубов и плейсхолдеров (Show/Hide).
- [ ] 2 замочных этапа: плейсхолдер-предмет с `IInteractable` → `CompleteObjective()`.
- [ ] Подсказки при повторе: звук из нужной комнаты на 2-м повторе.
- [ ] Грубый световой сценарий: свет меняется по `OnStageStarted`.
- [ ] **Плейтест №1** (3 человека). Чувствуется ли нарастание? Где застряли? Сколько длится каждый этап?

## Неделя 3 — **Решение по сюжету** + арт

- [ ] **Финализировать сюжет** (GDD, раздел 4): кто был в квартире, что случилось «той ночью», что открывается на каждом замочном этапе.
- [ ] Переписать таблицу этапов под сюжет.
- [ ] Ассеты квартиры из Fab / Quixel Megascans.

## Неделя 4 — Свет ⟶ главная фишка портфолио

- [ ] Свет этапа 0: тёплый, «живой» дом.
- [ ] Свет для каждого этапа: уход тепла, мерцание, темнота, финальный свет.
- [ ] Post Process и туман на этап.
- [ ] Скриншоты одной точки квартиры на всех 6 этапах. Это готовый слайд для портфолио.

## Неделя 5 — Контент и эскалация

- [ ] Финальные изменения под сюжет, 15+ штук на все этапы. Эскалация через BP `OnStageChanged`.
- [ ] Сюжетные предметы и записки.
- [ ] Звуковой пасс: room tone, который пропадает по этапам, шаги, подсказки.

## Неделя 6 — Пики и финал

- [ ] 1–2 сильных заскриптованных момента (этап 3–4). Один хороший испуг лучше десяти.
- [ ] Финал (`OnFinale`).
- [ ] Минимальное меню «Играть / Выход», пауза на Esc.

## Неделя 7 — Плейтесты и баланс

- [ ] **Плейтесты №2–3** (5+ человек). Метрики: время на этап, число повторов замочных этапов, понятен ли сюжет (пересказ после игры).
- [ ] Тюнинг подсказок: никто не должен застревать больше 3 повторов.
- [ ] Производительность: 60 FPS (`stat unit`, `stat gpu`).

## Неделя 8 — Портфолио-пакет ⟶ **M3: MVP готов**

- [ ] Shipping-сборка `.exe`, страница на itch.io.
- [ ] Трейлер 60–90 секунд.
- [ ] **Design breakdown**: столпы, кривая напряжения по этапам, световые схемы, эволюция блокаута, плейтест-метрики и что изменено по их итогам.

## Риски

| Риск | Что делать |
|---|---|
| Сюжет не решён и блокирует контент | Недели 1–2 работают на плейсхолдерах, жёсткий дедлайн решения: неделя 3 |
| Игрок застревает на замочном этапе | Нарастающие подсказки по `RepeatCount`, метрика повторов на плейтестах |
| Эскалация не чувствуется (всё страшно с начала) | Этапы 0–1 обязаны быть тихими. Проверять кривую на плейтестах |
| Пробуждение надоедает к 6-му кругу | Короткое затемнение (`FadeOutTime` / `WakeUpTime`), на поздних этапах — вариации пробуждения |
| Скоуп-крип | Список «вне MVP» в GDD. Новые идеи в `Docs/Backlog.md` |

## Definition of Done

- Игра проходится от этапа 0 до финала за 15–25 минут.
- Тестеры могут пересказать суть истории после игры.
- Никто не застревает на одном этапе больше 3 повторов.
- Этап узнаётся по одному скриншоту.
- Shipping-сборка запускается на чужом ПК.
